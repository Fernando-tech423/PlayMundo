# Sobre o PlayMundo

O PlayMundo é um site educativo dedicado à acessibilidade,
diversidade e sustentabilidade nos jogos digitais.

O projeto possui dez páginas desenvolvidas com HTML,
CSS e JavaScript.

## Funcionalidades

- Recursos de acessibilidade visual, motora, auditiva e cognitiva.
- Catálogo interativo de jogos.
- Comparação de recursos de acessibilidade.
- Guia de acessibilidade.
- Informações sobre impacto social.
